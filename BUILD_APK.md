# Как получить готовый APK без установки Android Studio

Сборку сделает GitHub бесплатно в облаке. Нужен только аккаунт GitHub.

## Шаги

1. Создайте новый репозиторий на github.com (кнопка "New", имя любое,
   можно Private).

2. Загрузите туда содержимое этой папки. Самый простой способ —
   на странице репозитория: "Add file" -> "Upload files" ->
   перетащить ВСЕ файлы и папки из архива (включая скрытую .github) ->
   Commit changes.

   Если .github не загружается через браузер (бывает со скрытыми папками),
   используйте git:
       git init
       git add .
       git commit -m "init"
       git branch -M main
       git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
       git push -u origin main

3. Перейдите во вкладку "Actions" репозитория. Сборка "Build APK"
   запустится автоматически после push (или нажмите "Run workflow").

4. Дождитесь зелёной галочки (~3-5 минут). Откройте завершённый запуск,
   внизу в разделе "Artifacts" скачайте "ScreenRotator-debug-apk".
   Внутри zip — файл app-debug.apk.

## Установка на телефон

1. Скиньте app-debug.apk на устройство.
2. Разрешите установку из неизвестных источников.
3. Откройте приложение и выдайте ДВА разрешения:
   - "Поверх других приложений" (overlay)
   - "Изменение системных настроек" (WRITE_SETTINGS)
4. Нажмите "Запустить кнопку".

Тап по плавающей кнопке — переключение ориентации по кругу (0/90/180/270).
Долгое перетаскивание — перемещение кнопки.

## Примечание
Это debug-APK, его достаточно для личного использования.
Приложения с жёстко фиксированной ориентацией игнорируют системный
поворот — это ограничение Android, не приложения.
